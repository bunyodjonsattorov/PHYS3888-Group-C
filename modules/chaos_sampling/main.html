Chaos vs a matched fake

Each series is either a real chaotic series (label 1) or a fake built to match it (label 0), and the algorithm has to say which. The fake has exactly the same values and almost the same power spectrum, so only the order of the values, the determinism, can give it away.

Two conditions, one system

Fine samplingEvery step of the system is recorded.
Coarse samplingEvery 4th step is recorded. The rule is still exact, but consecutive recorded values are now linked by the rule applied four times.

One logistic-map orbit (r = 3.99). Fine sampling keeps every point; coarse sampling keeps only the highlighted ones.

How the series are built

  • System: the logistic map x → r x (1 − x) with r drawn from 3.90, 3.95 and 3.99, where it is strongly chaotic.
  • Real series: 100-sample windows whose end matches their start, so the fake's wrap-around seam is not a giveaway. Every series is z-normalised.
  • Fake series: IAAFT surrogates: the same values, a power spectrum matched to within a few percent, and scrambled phases, which removes the determinism. The best of 20 attempts is kept.
  • Datasets: 50 rows each, 25 real and 25 fake, drawn from 50 different orbits. A fake never sits in the same dataset as the series it was made from, so a random train/test split cannot put a real series and its own twin on opposite sides.

How to read the result

Chance is 50%. Compare each algorithm across the two conditions: a drop from fine to coarse means it was using short-range structure that coarse sampling hides.

Limits

  • One system, and a one-dimensional map at that.
  • No measurement noise.
  • Ten small datasets per condition, each scored on one train/test split of about 35 training rows, so single results move around. Rely on the average over datasets.
