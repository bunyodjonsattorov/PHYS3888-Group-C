How the exponent-dispersion label is built

One univariate record per label, built on self-affine noise. Class 0 holds the local roughness exponent fixed, class 1 lets it vary along the record, and that is enough to leave the two classes with the same marginals and to put ROCKET at chance. Every figure and table below is drawn from the values embedded in this file.

1. The two series being mixed

Draw two independent fractional Gaussian noises, one at H = 0.4 and one at H = 0.9, and scale each to unit variance. Mix them sample by sample at an angle θ(t), then cumulatively sum the result to get the record.

fGn(H = 0.4) → r fGn(H = 0.9) → s → x(t) = cos θ(t)·r(t) + sin θ(t)·s(t) → Σ dt → record

r  H = 0.4, rough

s  H = 0.9, smooth

2. What separates the two classes

Both classes mix the same two series at the same amplitudes. Only θ(t) differs:

classθ(t)the mix
0 θ = π/4  (constant) a fixed 50/50 mix, so the roughness is the same everywhere in the record
1 θ = π/4 + 0.7 c(t) the mix drifts, so the local roughness varies along the record

c(t) is a smooth zero-mean field, so class 1 stays near the π/4 that class 0 fixes. θ sets how the variance is split between the two series, not how much variance there is:

x(t) = cos θ(t)·r(t) + sin θ(t)·s(t) cos²θ + sin²θ = 1 ⇒ Var[x(t)] = 1 for every t, in both classes

Every sample is Gaussian with variance exactly 1 whatever θ is doing, so the two classes have identical marginals: same variance, same kurtosis, same spectrum. In the figure below the two bands change shape but always sum to the same height.

3. The records

Cumulatively summing x(t) gives the record the classifier receives. These panels show the increments rather than the running sum, because over 1024 samples the sum is dominated by drift from the H = 0.9 series and its local texture is not visible at that scale. The sum is what gets classified, and in both classes it looks like a slow random walk.

4. Reading the label back with a window exponent

The record is split into 8 windows. In each window a structure function gives a local roughness exponent, the slope of log mean|Δlagx|² against log lag fitted over lags 1, 2, 4 and 8, so one number per window.

reader(record) = std of the 8 window roughness exponents ← the decision variable

In class 0 the eight exponents agree, so their spread is small; in class 1 they do not, so it is large. The reader needs no thresholds, fitted parameters or analyst-chosen cut.

5. ROCKET and the marginal tests

ROCKET's features are averages of how much local activity a kernel sees. The label changes what kind of activity it is while holding the magnitude fixed, so features of that kind have nothing to separate the classes on and the two clouds overlap. The marginal tests look at variance, kurtosis, zero-crossings and autocorrelation, all matched by the cos²+sin²=1 identity. This is a statement about detectability at this sample size rather than a theorem, and section 4 shows a reader that does see the difference. All four tests come out flat:
